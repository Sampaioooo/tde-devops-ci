# Prompt para Codex

Crie e revise um projeto Node.js para um TDE de Pratica DevOps.

Requisitos:
1. Usar JavaScript com CommonJS.
2. Criar uma classe chamada CalculadoraFinanceira em src/CalculadoraFinanceira.js.
3. A classe deve ter pelo menos 3 metodos: somarValores, aplicarDesconto e calcularParcelamento.
4. Criar testes unitarios com Jest em tests/CalculadoraFinanceira.test.js.
5. Configurar package.json com script test usando Jest.
6. Criar .github/workflows/main.yml para rodar em push e pull_request na main.
7. O workflow deve instalar dependencias com npm ci e rodar npm test.
8. Criar README e documentacao tecnica clara.
9. Manter o codigo simples, limpo e facil de explicar em apresentacao academica.
